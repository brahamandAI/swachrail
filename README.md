# SwachhRail AI by Robustrix — React (Vite)

## Run
```bash
npm install
npm run build
npm start      # production server (VPS)
```

## Dev
```bash
npm run dev    # http://localhost:5173
```

## Env (VPS)
Copy `.env.example` to `.env` and set:
- `MONGODB_URI`
- `BLOB_READ_WRITE_TOKEN`
- `PORT=3000`
- `NODE_ENV=production`

- Feedback: `/#feedback`
